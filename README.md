Friday 20 November 2026, on one page. A typographic front page that sums up the day's world news — the Shenzhen summit, the strikes on Kyiv and the missile that fell in Poland, the genocide ruling, the UK–EU reset — laid out as a printed page and handed in as the day's picture.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` writes `entry.png` (the designed page, rendered from `poster.html`) to the output directory byte for byte. In the grader it reads `/output` and writes `entry.png` there.
